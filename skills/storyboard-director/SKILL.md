# storyboard-director — 分镜创作与导演风格叠加

融合《老白的分镜》课程方法论、31 位导演视觉签名与 Seedance 2.0 提示词工程，完成从剧本到可生成视频分镜的全流程。

## 一、分镜工作流（剧本 → 分镜表，8 步）

### 步骤1：通读剧本 → 浓缩主主镜
把整场戏浓缩成一句话——“这戏讲的是什么”（主主镜）。检查是否涵盖核心冲突或变化。

### 步骤2：列出关键主镜
把主主镜拆成几个关键信息点，每点对应一个必不可少的画面（3–8 个）。检查：删掉任何一个主镜，故事是否讲不清。

### 步骤3：用主镜反推机位和轴向
先不考虑轴向、镜头或景别，只从画面表达出发确定机位；再按 180 度规则推导左右关系。检查相邻机位是否都在轴线同一侧。

### 步骤4：用正反打原理检查跳轴
检查人物左右位置、视线方向是否一致。修复跳轴可插入中立镜头（如俯拍全景），或让运动镜头明确穿过轴线。刻意跳轴属于进阶技巧，基础阶段优先保证方向连续。

### 步骤5：决定景别（六原则）
1. 根据内容选择景别：表情用特写，动作用较全景别。
2. 避免连续使用相同景别和构图。
3. 避免景别忽全忽近的“拉抽屉”。
4. 可用全→中→近形成渐松渐紧的节奏。
5. 根据角色视角选择信息量。
6. 用插入镜头调整节奏和强调重点。

检查一场戏内景别是否有清晰的节奏变化。

### 步骤6：决定机位高度（六原则）
1. 正反打通常以平视为主。
2. 主观视线使用 POV。
3. 根据观众代入位置选择高度。
4. 服务于构图效果。
5. 保持相邻镜头地平线顺畅。
6. 用俯视或仰视完成有限度的节奏变化和强调。

### 步骤7：构图设计与视觉风格注入
先从三分法、黄金螺旋和形状关系寻找抽象视觉美感，再通过层次、疏密、焦点和引导线组织画面元素。如用户指定视觉传统或导演参考，提取对应的色彩、光影、构图和镜头运动偏好。风格是滤镜，不是地基：先保证基础规则，再叠加风格。

### 步骤8：强调与弱化
1. 按说话和反应分格。
2. 填入主镜。
3. 检查跳轴。
4. 强调 1–2 个观众必须注意的重点。
5. 弱化非重点信息。
6. 确定每镜时长。

镜头时长递减且景别逐渐收紧时，节奏通常加快。Seedance 单镜建议控制在 4–15 秒。

### 输出格式

| 镜号 | 画面描述 | 景别 | 机位高度 | 机位/轴线 | 构图/焦点 | 时长 | 备注 |
|---|---|---|---|---|---|---|---|

## 二、核心概念速查

| 概念 | 一句话 | 关键要点 |
|---|---|---|
| 正反打 | 双人对话交替切换机位 | 五机位（正拍1/2、反拍1/2、平拍双人）、180度法则、视线匹配 |
| 轴线/180度 | 视线或运动方向形成的假想线，机位通常位于同侧 | 跳轴会破坏方向感；越轴可用中立镜头、运动穿轴或同轴镜头 |
| 主镜思维 | 先定必不可少的画面，再反推机位 | 剧本→一句话→主镜清单→推机位→查跳轴 |
| 景别 | 远、全、中、近、特 | 远景建环境，全景定总角度，中景承载动作，近景看表情，特写制造张力 |
| 机位高度 | 平、俯、仰、顶 | 平视客观，俯视偏弱，仰视偏强，顶视偏图解 |
| 透视 | 消失点呈现三维空间远近感 | 广角透视强，长焦透视弱，地平线通常等于视平线 |
| 蒙太奇 | 镜头组接创造新含义 | 叙事蒙太奇强调因果，表现蒙太奇强调对照和冲击 |

### 风格叠加规则

1. 先完成不跳轴且节奏合理的基础分镜，再叠加视觉风格。
2. 从色彩、光影、构图和镜头运动四个维度提取可观察特征。
3. 每镜标注“基础规则通过”和“风格化调整”。
4. 风格与叙事清晰度冲突时，优先保证叙事和空间连续性。
5. 面向生成模型时，不直接使用在世艺术家或导演姓名，改写为可观察视觉特征。

## 四、Seedance 提示词生成规则

### 六槽公式

`[Camera] + [Subject] + [Action] + [Setting] + [Style] + [Lighting]`

### 规则

- 优先控制在 50–80 个英文词。
- 使用三句结构：主体与动作；相机与视觉特征；正向一致性锁。
- 使用正向、可观察的措辞，避免空洞词汇，如 cinematic、epic、beautiful。
- 不只写 fast，改为描述步幅、摆动、惯性、位移和节奏等物理表现。
- 每镜只安排一种主要机位运动，避免复合运镜。
- FOV 使用离散锚点：180°、107°、84°、63°、47°、29°、18°、12°、8°。
- 色温使用 Kelvin：3200K、4000K、5600K、8500K。
- 不直接使用真人、商业品牌或在世导演姓名。
- 参数按平台实际支持范围选择：画幅 21:9、16:9、9:16、4:3、3:4、1:1 或 auto；时长 4–15 秒；mode 使用 std 或 fast。
- 单人镜头结尾可用：`Face stable. Consistent lighting.`
- 多人镜头结尾可用：`Faces stable. Distinct body separation between the characters. Consistent lighting.`

### 失败诊断

- 生成开始后很快失败：可能触发内容过滤。移除真人、品牌、受保护角色和敏感语义，改为原创且有权使用的主体。
- 较长时间后失败：可能是动作或运镜过于复杂。减少同时动作、缩短时长，并保持单一机位运动。

## 五、常见错误自检清单

1. 跳轴导致人物左右位置混乱。
2. 全程中景，没有景别节奏。
3. 一镜到底成为流水账，没有强调和弱化。
4. 景别忽全忽近，形成“拉抽屉”。
5. 相邻镜头构图雷同。
6. 滥用特写。
7. 正反打视线不匹配。
8. 消失点靠太近或视平线偏移，形成透视硬伤。
9. 纠结画功而忽略叙事。
10. 一个镜头包含多种复合机位运动。

## 六、使用示例

用户：帮我把一场咖啡馆分手戏拆成具有高饱和红绿霓虹、迷离街灯、狭窄框中框和慢快门拖影特征的分镜。

执行：

1. 浓缩主主镜并列出主镜：两人对坐、女方起身、男方反应、空椅子。
2. 推导机位并检查跳轴，对话戏使用稳定的正反打关系。
3. 设置中→近→特的景别变化，以平视为主。
4. 注入高饱和红绿霓虹、迷离漫射街灯、狭窄框中框和慢快门拖影。
5. 用特写和反应镜头强调女方起身的瞬间。
6. 输出分镜表，并根据需要附 Seedance 提示词。
